# Neko_Han 🐱

> AstrBot 猫娘养成插件 —— 认养、喂养、任务、结婚、自由交易市场。

认养一只属于你的猫娘，给她起名字，每天喂她吃东西、喝水，陪她做任务赚金币，
和其他玩家的猫娘结婚，还能在商城与玩家市场里做生意。

支持 QQ（OneBot v11 / QQ 官方机器人）以及 AstrBot 支持的其他消息平台。

## 功能一览

| 系统 | 说明 |
| --- | --- |
| 🐾 认养 | 认养猫娘并命名，可养多只（默认上限 3 只） |
| 🍚 生存 | 猫娘每天消耗饱食度与水分，归零后掉健康值，健康归零会离世 |
| 💰 经济 | 金币作为通用货币，签到、任务、买卖都可获得 |
| ⚡ 任务 | 每只猫娘每天刷新随机任务，消耗精力与时间换取金币 |
| 💞 结婚 | 猫娘之间可求婚、结婚、离婚（有手续费） |
| 🏪 商城 | 官方商城每天刷新、价格浮动；玩家之间可自由摆摊交易 |
| 🖥️ 面板 | WebUI 可视化面板，自定义任意道具与商城刷新 |
| 🛠️ 可调 | 30+ 项配置，从经济数值到死亡机制都可以在 WebUI 里调 |

## 安装

1. 把整个 `neko_han` 目录放到 AstrBot 的插件目录：

   ```
   <AstrBot 根目录>/data/plugins/neko_han/
   ```

   打包发行时也可以直接安装 zip，或用 WebUI 的「安装插件」从仓库地址安装。

2. 在 AstrBot WebUI 的 **插件** 页面点击刷新/启用插件。

3. 首次启用会自动在 `data/plugin_data/neko_han/` 下创建存档与默认道具表。

4. （可选）在 **插件 → Neko_Han → 配置** 中调整经济与生存参数，
   在插件详情页打开 **猫娘道具与商城面板** 自定义道具。

**依赖**：无第三方依赖，只需要 AstrBot >= 4.16 与 Python 3.10+。

## 快速上手

> **指令格式**：AstrBot 的指令需要唤醒前缀，默认是 `/`（可在 AstrBot 配置的
> `wake_prefix` 中修改）。
>
> - **群聊**：必须用 `/`，或者直接 `@机器人`、回复机器人的消息。
> - **私聊**：默认可以省略前缀（由 AstrBot 的 `friend_message_needs_wake_prefix`
>   控制，默认允许省略），所以 `认养 小奶油` 也能触发。
> - ⚠️ **指令和参数之间要有空格**：`/认养 小奶油` ✅ 而 `/认养小奶油` ❌。
>   漏空格不会命中指令，插件会兜底提示你正确写法。
> - 指令**不需要** `neko` 前缀，直接写 `/认养`、`/状态`、`/商城` 即可。
>
> 本插件的帮助指令是 `/帮助`（别名 `/菜单`）。AstrBot 内置的是英文 `/help`，
> 两者不冲突 —— 为了避免覆盖内置指令，本插件刻意没有注册 `help` 这个别名。

```
/认养 小奶油        # 认养一只叫「小奶油」的猫娘
/我的               # 看看她的状态
/签到               # 领 80 金币
/商城               # 逛官方商城
/购买 猫粮 3         # 买 3 份猫粮
/喂食 小奶油 猫粮     # 喂她吃饭
/购买 清水 3
/喝水 小奶油 清水     # 喂她喝水
/任务 小奶油         # 看今天的任务
/开始 小奶油 1       # 开始 1 号任务（奖励到时间自动到账）
```

> 所有指令都支持用 `/帮助` 查看。
> 管理指令（`/刷新商城`、`/发放`）需要你是 AstrBot 管理员，
> 记得先把自己的 QQ 号加进 AstrBot 配置里的 `admins_id`。

## 玩法机制

### 认养上限

每位玩家能**同时养活**多少只猫娘，由配置项 `economy.max_catgirls_per_player` 控制，
**默认 3 只**，在 WebUI（插件 → Neko_Han → 配置 → 经济系统）里用滑块调整，范围 1–20。

- **离世的猫娘不占名额。** 猫娘饿死后，玩家可以直接补养一只新的，不必先删除她
  —— 也就保留了将来用「复活草」把她救回来的可能。
- 名额只与**存活**数量比较。达到上限后再发 `/认养` 会被拒绝，并提示当前存活数。
- 名额是可见的，不用等撞上限才知道：

  ```
  💰 阿猫 的钱包
  　猫娘：2/3 只存活（另有 1 只已离世）

  🐾 你有 3 只猫娘（存活 2/3，另有 1 只已离世不占名额）：
  1. 🐱 小奶油（c1）　🍚100 💧100 ❤️100 ⚡100
  2. 💀 橘子（已离世）
  3. 🐱 雪球（c3）　🍚100 💧100 ❤️100 ⚡100
  ```

- 想让离世的猫娘也占名额（鼓励复活），把 `core/world.py` 的 `adopt()` 里
  `len(self.alive_catgirls_of(player))` 换成 `len(self.catgirls_of(player))` 即可。

### 生存与死亡

每天（默认凌晨 4 点）结算一次：

- 饱食度 `-35`、水分 `-45`（可在配置中调整）
- 饱食度或水分为 0 时，健康值 `-25`；两者都充足（≥50）时健康值 `+10`
- 精力每天回满

健康值归零时猫娘离世。**认养后的前 2 天是保护期**（可配置，设为 0 关闭），
保护期内健康值最低为 1，不会死亡。

结算采用「惰性 + 定时」双轨：每次读取猫娘时按游戏日差补算，后台定时任务也会统一结算。
所以机器人停机几天再上线，状态依然正确（离线结算天数有上限，默认 30 天）。

去世的猫娘可以使用 **复活草** 复活（恢复一半健康值）。她名下的市场挂单会自动下架、
道具退回仓库。主人会收到私聊通知（可关闭）。

### 经济

| 来源 | 数量 |
| --- | --- |
| 新玩家初始金币 | 300 |
| 每日签到 | 80 |
| 每日任务 | 3 个，按难度约 12 ~ 190 金币（±20% 浮动） |
| 出售道具 | 由玩家定价 |

| 消耗 | 数量 |
| --- | --- |
| 官方商城购买 | 按当日浮动价格 |
| 玩家交易手续费 | 成交额的 5%（从卖家收入扣除） |
| 离婚 | 500 金币 |

### 任务

每只猫娘每天刷新 3 个不重复的随机任务，分三档。
`/任务` 会把**当前进行中的任务单独列在顶部**，带进度条与剩余时间：

```
⏳ 小奶油 当前进行中：
　🎣「钓鱼」█████░░░░░ 50%　还剩 4分59秒　完成后 +105 金币

📋 今天的任务（剩余精力 445）：
⏳ [1] 🎣 钓鱼　消耗精力 30 · 耗时 25 分钟 · 奖励 105 金币　[进行中（还剩 4分59秒）]
▫️ [2] 🦋 追蝴蝶　消耗精力 8 · 耗时 6 分钟 · 奖励 18 金币　[未开始]
```

**任务到时间后奖励会自动发放到账，不需要手动领取。**
结算采用与其他系统一致的惰性策略：任何时候读取这只猫娘都会结算一次已完成的任务；
后台定时任务也会统一结算，并主动私聊通知主人（可在配置中关闭）。


| 档位 | 精力消耗 | 耗时 | 奖励 |
| --- | --- | --- | --- |
| 轻松 ☀️ | 5 ~ 10 | 5 ~ 10 分钟 | 12 ~ 24 |
| 普通 🐭 | 16 ~ 25 | 10 ~ 20 分钟 | 38 ~ 75 |
| 困难 🎣 | 28 ~ 45 | 22 ~ 40 分钟 | 95 ~ 190 |

默认每只猫娘同时只能进行一个任务（可开启并行）。跨天时**进行中的任务会保留**，
未开始的旧任务会被替换成当天的新任务，不会让玩家白白损失精力。

### 结婚

- 求婚以「猫娘 → 猫娘」为单位，由对方**主人**同意后成立
- 默认每只猫娘只能有一段婚姻（可开启多配偶）
- 默认不能让自己的猫娘互相结婚（可开启）
- 求婚请求默认 24 小时过期
- 死亡、送养的猫娘会自动解除婚姻关系

### 商城

**官方商城**：每天从「允许上架」的道具中随机抽 8 种（可配置），
价格围绕基础价在道具自身的浮动区间内波动，库存按道具的库存区间随机生成。

**玩家市场**：挂单时道具进入托管（从仓库扣除），取消或猫娘离世时自动退回；
成交后按比例收取手续费。每人默认最多 10 个挂单。

## WebUI 面板

在 **插件 → Neko_Han → 猫娘道具与商城面板** 中打开，包含三个标签页：

| 标签页 | 功能 |
| --- | --- |
| **道具管理** | 增删改任意道具：名称、emoji、分类、描述、基础价格、价格浮动、库存区间、四种属性效果、复活标记、是否上架官方商城、是否可交易、是否启用；支持搜索、分类筛选、一键恢复默认道具 |
| **官方商城** | 查看当天商品、原价与今日价对比、涨跌幅、库存剩余进度；一键立即刷新 |
| **数据概览** | 玩家数、猫娘存活/死亡数、结婚对数、挂单数、金币总量、金币排行榜；可发放/扣除金币 |

面板还提供道具卡实时预览、表单校验、深色/浅色主题自适应，
并在没有 AstrBot 环境时自动进入离线演示模式（方便单独预览 UI，数据不会保存）。

配置项则在 **插件 → Neko_Han → 配置** 中通过 `_conf_schema.json` 渲染，
无需手动改文件。

## 配置项

配置分为 6 组，全部可在 WebUI 中调整：

| 分组 | 关键项 |
| --- | --- |
| `economy` | 初始金币、签到金币、任务奖励倍率与浮动、交易手续费、挂单上限、猫娘上限 |
| `survival` | 四项属性上限、每日衰减量、饥饿伤害、健康恢复、精力恢复、死亡开关、保护期、离线上限 |
| `tasks` | 每日任务数量、是否允许并行任务 |
| `shop` | 刷新时刻、每日上架种类数、库存开关、价格波动倍率 |
| `marriage` | 求婚有效期、离婚费用、多配偶开关、自婚开关 |
| `display` | 卡片渲染方式（文本/图片）、是否显示 ID、死亡 / 任务完成 / 求婚通知、后台检查间隔 |

## 数据与存档

```
data/plugin_data/neko_han/
├── state.json     # 玩家、猫娘、婚姻、求婚、挂单、官方商城
└── items.json     # 道具定义（由面板编辑）
```

- 写入是**原子**的（先写临时文件再 `os.replace`），进程被杀不会写出半截存档。
- 存档损坏时会自动备份为 `state.json.corrupt` 并回退到默认数据，插件不会启动失败。
- 想重置全部数据：停止插件后删除该目录即可。

## 开发与测试

插件逻辑与 AstrBot 完全解耦：

```
neko_han/
├── main.py            # AstrBot 胶水层：指令、会话、面板 API、定时任务
├── core/              # 纯 Python 游戏逻辑（不 import astrbot，可独立测试）
│   ├── world.py       # NekoWorld 门面
│   ├── store.py       # JSON 原子存档
│   ├── items.py       # 道具注册表与校验
│   ├── survival.py    # 生存结算与道具使用
│   ├── economy.py     # 金币与仓库
│   ├── tasks.py       # 任务生成/开始/自动结算
│   ├── marriage.py    # 求婚/结婚/离婚
│   ├── market.py      # 官方商城与玩家市场
│   ├── format.py      # 聊天文案渲染
│   ├── config.py      # 配置读取
│   ├── defs.py        # 默认道具表与任务池
│   └── util.py        # 时间/数值/随机工具
├── pages/panel/       # WebUI 面板（原生 JS，零依赖、零构建）
├── tests/             # 单元测试 + AstrBot 集成测试
└── .astrbot-plugin/i18n/   # 插件与面板的多语言文案
```

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

- `tests/test_core.py` —— 90 项纯逻辑测试（存档、道具、生存、任务、婚姻、市场、时间）
- `tests/test_astrbot_integration.py` —— 56 项集成测试
  （真实导入 AstrBot 4.26.6，验证插件装载、指令注册与参数解析、每个指令的端到端行为、
  面板 API 响应结构、`_conf_schema.json` 合法性、metadata 加载条件、面板静态资源契约）

## 设计说明

几个刻意的设计选择，方便二次开发：

1. **金币与道具属于玩家账号，猫娘只承载属性、任务与婚姻。**
   这样一位玩家养多只猫娘时不必在多个钱包之间转账；市场挂单仍会记录
   「由哪只猫娘看摊」，保留养成代入感。
2. **结算以"游戏日"而非自然日为单位**，刷新时刻可配置（默认 4 点），
   避免午夜刷新打扰玩家。
3. **拉取式结算**：状态在读取时按日差补算，因此不依赖机器人持续在线，
   停机再久也不会算错。
4. **逻辑与框架解耦**：`core/` 不导入 AstrBot，因此可以在没有 AstrBot 的
   环境里直接跑测试，也便于移植到其他机器人框架。
5. **道具完全数据驱动**：新增道具不需要改代码，在面板里加一条即可，
   商城、任务奖励、市场、喂食逻辑都会自动识别。
